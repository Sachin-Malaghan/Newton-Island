Privacy policy

Last updated 5 October 2026

The short version

CURIO ISLES does not collect, store, share or sell any personal information. There are no accounts, no ads, no analytics and no tracking of any kind, in the game or on this website.

What the game stores

The game saves a small file on your own device with your progress (stars earned, concept cards collected, the last level you played) and your settings (Fun or Student Mode, sound). This file never leaves your device. Deleting the game deletes it.

Network access

The game does not need an internet connection and does not send anything over the network.

Permissions

On Android and iOS the game asks for no special permissions: no location, camera, microphone, contacts or photos.

Children

Because no personal information is collected from anyone, none is collected from children.

This website

This site uses no cookies, no analytics and no third-party scripts or fonts. The host that serves the pages may keep standard server logs (such as IP addresses) for security, as all web hosts do.

Changes

If a later version adds purchases, ads or anything that touches data, this page will be updated before the game is, and the date above will change.

Contact

Brainrot Interactive Studios — see the developer contact on the game's store page.
