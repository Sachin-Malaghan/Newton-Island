# CURIO ISLES

*Break it. Fix it. Understand it.*

A puzzle adventure across an archipelago of science islands. Each level is a broken machine: put parts from
the tray into it, set their sliders to real quantities (height, angle, speed, braking), press PLAY and watch
the chain reaction — the machine comes back to life and you learn why it worked. Island 1 is Newton's
Island (Physics); Fun Mode hides the numbers, Student Mode shows units, measurements and formulas.

Unreal Engine 5.8, C++. Android first, iOS later, Windows for development.
By Brainrot Interactive Studios.

- `CLAUDE.md` — the project spec and how to build, test and run.
- `SETUP.md` — machine setup and release steps.
- `Content/Islands/` — all game content (JSON).
